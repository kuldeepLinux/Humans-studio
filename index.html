What this version can do

Live camera face tracking detects head direction and eye-blink blendshapes. Portrait mode adds interactive perspective motion to your uploaded photo. This is not yet a reconstructed 3D identity: a single photo cannot reveal unseen side surfaces or create a true 3D face. A production-grade 3D clone needs a dedicated reconstruction model/API and more input views.

Use only your own face or a person’s face with their clear permission. Camera access requires HTTPS or localhost; GitHub Pages provides HTTPS.
